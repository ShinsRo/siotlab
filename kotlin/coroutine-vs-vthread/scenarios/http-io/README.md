# HTTP I/O

`http-io` 시나리오는 외부 HTTP 서버를 대상으로 코루틴과 가상 스레드의 I/O 처리 특성을 비교하는 실험이다.

## 방향

- 테스트 실행 시 필요한 HTTP 서버는 Testcontainers로 기동한다.
- 아직 구현 코드는 작성하지 않는다.
- 먼저 시나리오 정의와 실험 목적을 문서로 정리한 뒤 구현에 들어간다.

## 목표

- 동일한 HTTP 요청 workload에서 코루틴과 가상 스레드의 처리 시간을 비교한다.
- 연결 수, 요청 수, 응답 지연 조건에 따라 어떤 차이가 나는지 본다.
- `sleep-io`보다 실제 네트워크 I/O에 가까운 조건에서 결과를 확인한다.

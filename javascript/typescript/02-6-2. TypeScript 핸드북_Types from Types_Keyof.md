# Keyof Type Operator

## `keyof` 연산자

- 객체 타입을 받아 → 그 키들의 **문자열/숫자 리터럴 유니언** 을 반환

```typescript
type Point = { x: number; y: number };
type P = keyof Point; // "x" | "y"
```

- 인덱스 시그니처가 있는 타입에 `keyof` 를 적용하면 인덱스 타입이 나옴

```typescript
type Arrayish = { [n: number]: unknown };
type A = keyof Arrayish; // number

type Mapish = { [k: string]: boolean };
type M = keyof Mapish;   // string | number
// 주의: JS 에서 obj[0] 과 obj["0"] 이 같으므로 string 키는 자동으로 number 도 포함
```

## 활용

- `keyof` 는 매핑된 타입 (mapped types) 이나 제네릭 제약과 함께 자주 사용됨

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const person = { name: "Alice", age: 30 };
getProperty(person, "name"); // string
getProperty(person, "age");  // number
getProperty(person, "foo");  // error
```

- 위 예시는 `keyof` + 인덱스 접근 타입 (`T[K]`) 조합의 대표적인 활용

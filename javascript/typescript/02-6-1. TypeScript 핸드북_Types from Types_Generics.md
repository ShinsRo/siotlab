# Generics

- 재사용 가능한 컴포넌트를 만드는 도구
- 특정 타입이 아니라 **다양한 타입에서 동작** 할 수 있게 함

## 제네릭의 Hello World

- `any` 를 쓰면 반환 타입 정보가 사라짐

```typescript
function identity(arg: any): any { return arg; }
```

- 타입 파라미터를 도입 → 입력과 출력을 연결

```typescript
function identity<Type>(arg: Type): Type { return arg; }

let output = identity<string>("myString"); // string
let output2 = identity("myString");        // 타입 인자 추론
```

- 두 번째 호출처럼 타입 인자를 생략 → TS 가 인자로부터 추론

## 제네릭 타입 변수와 작업하기

- 제네릭 함수 안에서는 그 타입이 어떤 타입인지 모른다고 가정하고 다뤄야 함

```typescript
function loggingIdentity<Type>(arg: Type): Type {
  console.log(arg.length); // error: Type 에 length 가 있다고 보장 못함
  return arg;
}
```

- 배열이라고 가정하면 가능

```typescript
function loggingIdentity<Type>(arg: Type[]): Type[] {
  console.log(arg.length); // OK
  return arg;
}
```

## 제네릭 타입 (Generic Types)

- 함수의 타입을 제네릭으로 표현 가능

```typescript
function identity<Type>(arg: Type): Type { return arg; }

let myIdentity: <Type>(arg: Type) => Type = identity;
// 또는 다른 이름의 파라미터로
let myIdentity2: <Input>(arg: Input) => Input = identity;
// 호출 시그니처 형태로
let myIdentity3: { <Type>(arg: Type): Type } = identity;
```

- 인터페이스로 표현

```typescript
interface GenericIdentityFn { <Type>(arg: Type): Type; }
let myIdentity: GenericIdentityFn = identity;

// 타입 파라미터를 인터페이스 전체로 이동 → 잠금
interface GenericIdentityFn<Type> { (arg: Type): Type; }
let myIdentity2: GenericIdentityFn<number> = identity;
```

## 제네릭 클래스 (Generic Classes)

```typescript
class GenericNumber<NumType> {
  zeroValue: NumType;
  add: (x: NumType, y: NumType) => NumType;
}

let myGenericNumber = new GenericNumber<number>();
myGenericNumber.zeroValue = 0;
myGenericNumber.add = (x, y) => x + y;
```

- 인스턴스 멤버에만 적용, static 멤버에는 사용 불가

## 제네릭 제약 (Generic Constraints)

- 타입 파라미터가 특정 조건을 만족해야 할 때 `extends` 사용

```typescript
interface Lengthwise { length: number; }

function loggingIdentity<Type extends Lengthwise>(arg: Type): Type {
  console.log(arg.length); // OK
  return arg;
}

loggingIdentity(3);                 // error
loggingIdentity({ length: 10, value: 3 }); // OK
```

## 제네릭 제약에서 타입 파라미터 사용

- 다른 타입 파라미터에 의해 제약되는 파라미터를 선언 가능

```typescript
function getProperty<Type, Key extends keyof Type>(obj: Type, key: Key) {
  return obj[key];
}

let x = { a: 1, b: 2, c: 3, d: 4 };
getProperty(x, "a");    // OK
getProperty(x, "m");    // error: "m" 은 keyof x 아님
```

## 제네릭에서 클래스 타입 사용

- 팩토리 함수 등에서 `new` 로 생성 가능한 타입을 표현

```typescript
function create<Type>(c: { new (): Type }): Type {
  return new c();
}
```

- 고급 예: 프로토타입 기반으로 인스턴스와 생성자를 연결

```typescript
class BeeKeeper { hasMask: boolean = true; }
class ZooKeeper { nametag: string = "Mikle"; }
class Animal { numLegs: number = 4; }
class Bee extends Animal { keeper: BeeKeeper = new BeeKeeper(); }
class Lion extends Animal { keeper: ZooKeeper = new ZooKeeper(); }

function createInstance<A extends Animal>(c: new () => A): A {
  return new c();
}

createInstance(Lion).keeper.nametag;
createInstance(Bee).keeper.hasMask;
```

## 제네릭 파라미터 기본값 (Generic Parameter Defaults)

- 타입 파라미터에도 기본값 지정 가능

```typescript
declare function create<T extends HTMLElement = HTMLDivElement, U = T[]>(
  element?: T,
  children?: U
): Container<T, U>;
```

- 기본값 규칙
    - 기본값이 있는 파라미터는 선택적으로 취급됨
    - 필수 파라미터는 선택적 파라미터 뒤에 올 수 없음
    - 기본값은 제약을 만족해야 함

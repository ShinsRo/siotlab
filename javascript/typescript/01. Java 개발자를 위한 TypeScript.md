# TS for Java Programmers

## Rethinking the class

### 의무적 OOP 언어(C#, Java)와의 차이

- 클래스가 동작의 기본 컨테이너가 아님
- 함수가 클래스에 속하지 않고 자유로움
- 정적 클래스, 싱글톤과 같은 특정 구조가 필요하지 않음

## TypeScript 의 OOP

- 클래스의 개념이 존재하므로, OOP 계층에 따른 해법 사용 가능
- 인터페이스, 상속, 정적 메서드 구현과 같은 일반 패턴 지원

## Rethinking Types

**타입에 대한 이해는 Java 와 상당히 다르다.**

### Nominal Reified Type Systems

- Java, C# 의 값과 객체는 - null, Primitive, Defined Class 중 하나
- (결국 런타임에 타입 정보가 없다는 말을 하고 싶은 듯 - 코틀린의 reifined 떠올리자. 근데 nominal 은 뭐지)
- 코드에서 사용한 타입은 런타임 시점에 존재. 타입은 구조가 아닌 선언을 통해 연관

### Types as Sets

- Java, C# : 런타입 타입과 컴파일 이임  타선언 사이 1:1 대응이 중요
- TypeScript : 공통의 무언가를 공유하는 값의 집합 - 타입은 집합에 불과하며 특정 값은 동시에 수많은 집합에 속할 수 있음
- ex. C# 에서 string 과 int 둘 다 가능한 타입은 이상함 - 타입스크립트에서는 union: string | number

### 삭제된 Structural Types

- 객체는 정확히 단일 타입이 아님
- 인터페이스와 객체, 둘 사이 선언적 관계가 없더라도 인터페이스에 해당 객체를 대입, 사용 가능

```typescript
interface Pointlike {
  x: number;
  y: number;
}
interface Named {
  name: string;
}
function printPoint(point: Pointlike) {
  console.log("x = " + point.x + ", y = " + point.y);
}
function printName(x: Named) {
  console.log("Hello, " + x.name);
}
const obj = {
  x: 0,
  y: 0,
  name: "Origin",
};

printPoint(obj);
printName(obj);
```

- 타입 간의 관계는 선언아 아닌 포함 프로퍼티에 의해 결정
- 타입 시스템은 구체화되어 있지 않음: 런타임에 `obj` 가 `Pointlike` 임을 모름. 애초에 `Pointlike` 는 런타임에 존재하지 않음 (? reifined 라며. 뭐지?)
- 집합의 개념에서, `obj` 는 `Pointlike` 값 집합 혹은 `Named` 값 집합의 멤버

### 구조적 타입화의 결과

#### Empty Types

```typescript
class Empty {}
function fn(arg: Empty) {
  // 
}
// 
fn({ k: 10 });
```

- 인자가 상기 `Empty` 인지 확인할 때 구조를 확인하여 유효성을 검사함
- `Empty` 에 프로퍼티가 없으므로, `Empty` 의 모든 프로퍼티가 `{ k: 10 }` 속하므로, 유효함

#### Identical Types

```typescript
class Car {
  drive() {
  }
}
class Golfer {
  drive() {
  }
}
// No error?
let w: Car = new Golfer();
```

- 클래스 구조가 동일하므로, 오류가 아님
- (그러나 혼란의 이유가 될 수는 있음)

#### Reflection

```C#
// C#
static void PrintType<T>() {
    Console.WriteLine(typeof(T).Name);
}
```

- 타입스크립트에서 제네릭 타입 인자의 인스턴스화와 같은 정보는 런타임에 사용할 수 없음
- JS 에 `typeof`, `instanceof` 와 같은 제한된 원시요소가 있지만, 이런 연산자는 여전히 작동함에 주의
- ex. `typeof (new Car())`는 `Car` 나 `"Car"` 가 아닌 `"object"`

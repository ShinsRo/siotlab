# Mapped Types

## 매핑된 타입

- 기존 타입의 키를 순회하며 새로운 타입을 만드는 방식
- 인덱스 시그니처 문법을 기반으로 함

```typescript
type OnlyBoolsAndHorses = {
  [key: string]: boolean | Horse;
};

const conforms: OnlyBoolsAndHorses = {
  del: true,
  rodney: false,
};
```

- `[P in K]` 형태로 유니언 `K` 의 각 멤버를 키로 순회

```typescript
type OptionsFlags<Type> = {
  [Property in keyof Type]: boolean;
};

type Features = {
  darkMode: () => void;
  newUserProfile: () => void;
};

type FeatureOptions = OptionsFlags<Features>;
// { darkMode: boolean; newUserProfile: boolean; }
```

## 매핑 수정자 (Mapping Modifiers)

- `readonly` 와 `?` 두 가지 수정자를 매핑 중에 추가하거나 제거 가능
- `+` (추가) 또는 `-` (제거) 접두사 사용
- 접두사를 생략하면 `+` 로 간주

```typescript
// readonly 제거
type CreateMutable<Type> = {
  -readonly [Property in keyof Type]: Type[Property];
};

type LockedAccount = {
  readonly id: string;
  readonly name: string;
};

type UnlockedAccount = CreateMutable<LockedAccount>;
// { id: string; name: string; }
```

```typescript
// 선택적 프로퍼티 제거
type Concrete<Type> = {
  [Property in keyof Type]-?: Type[Property];
};

type MaybeUser = { id: string; name?: string; age?: number; };
type User = Concrete<MaybeUser>;
// { id: string; name: string; age: number; }
```

## `as` 를 통한 키 재매핑 (Key Remapping via `as`)

- TS 4.1+ : `as` 절로 매핑 시 키를 변형 가능

```typescript
type MappedTypeWithNewProperties<Type> = {
  [Properties in keyof Type as NewKeyType]: Type[Properties];
};
```

- 예: 템플릿 리터럴 타입으로 getter 만들기

```typescript
type Getters<Type> = {
  [Property in keyof Type as `get${Capitalize<string & Property>}`]:
    () => Type[Property];
};

interface Person { name: string; age: number; location: string; }
type LazyPerson = Getters<Person>;
// { getName: () => string; getAge: () => number; getLocation: () => string; }
```

- 조건부 타입과 결합해 특정 키를 제거

```typescript
type RemoveKindField<Type> = {
  [Property in keyof Type as Exclude<Property, "kind">]: Type[Property];
};

interface Circle { kind: "circle"; radius: number; }
type KindlessCircle = RemoveKindField<Circle>; // { radius: number; }
```

- 유니언에 대해서도 매핑 가능

```typescript
type EventConfig<Events extends { kind: string }> = {
  [E in Events as E["kind"]]: (event: E) => void;
};

type SquareEvent = { kind: "square"; x: number; y: number };
type CircleEvent = { kind: "circle"; radius: number };

type Config = EventConfig<SquareEvent | CircleEvent>;
// { square: (event: SquareEvent) => void; circle: (event: CircleEvent) => void; }
```

## 추가 탐구

- 매핑된 타입은 조건부 타입, `infer`, 템플릿 리터럴 타입 등과 결합해 매우 강력한 유틸리티를 만들 수 있음
- 표준 유틸리티 타입 (`Partial`, `Readonly`, `Pick`, `Record` 등) 이 모두 매핑된 타입 기반

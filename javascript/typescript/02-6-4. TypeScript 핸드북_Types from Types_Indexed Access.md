# Indexed Access Types

## 인덱스 접근 타입

- 다른 타입의 특정 프로퍼티 타입을 조회할 수 있음
- JS 에서 값에 대해 `obj["key"]` 로 접근하듯이, 타입에서도 유사한 문법

```typescript
type Person = { age: number; name: string; alive: boolean };
type Age = Person["age"]; // number
```

## 유니언, keyof 활용

- 인덱스 자체가 타입이므로 유니언, `keyof` 등 어떤 타입도 사용 가능

```typescript
type I1 = Person["age" | "name"]; // string | number
type I2 = Person[keyof Person];   // string | number | boolean

type AliveOrName = "alive" | "name";
type I3 = Person[AliveOrName];    // string | boolean
```

- 존재하지 않는 키를 넣으면 에러

```typescript
type I1 = Person["alve"]; // error: "alve" 는 Person 의 키가 아님
```

## 배열 요소 타입 얻기

- `number` 를 인덱스로 사용해 배열 요소 타입을 얻을 수 있음
- `typeof` 와 조합하면 편리

```typescript
const MyArray = [
  { name: "Alice", age: 15 },
  { name: "Bob", age: 23 },
  { name: "Eve", age: 38 },
];

type Person = typeof MyArray[number];
// { name: string; age: number }

type Age = typeof MyArray[number]["age"]; // number
// 또는
type Age2 = Person["age"];                // number
```

## 값이 아닌 타입만 인덱스로 사용 가능

- `const` 로 선언된 상수라도 값을 인덱스로 사용할 수 없음
- 필요하면 `typeof` 로 타입을 얻어 사용

```typescript
const key = "age";
type Age = Person[key]; // error

type key = "age";
type Age = Person[key]; // OK
```

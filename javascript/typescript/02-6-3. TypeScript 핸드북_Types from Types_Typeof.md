# Typeof Type Operator

## `typeof` 타입 연산자

- JS 의 `typeof` 는 런타임에 문자열을 반환 (`"string"`, `"number"` 등)
- TS 의 `typeof` 는 **타입 컨텍스트** 에서 사용 → 어떤 변수/프로퍼티의 **타입** 을 참조

```typescript
let s = "hello";
let n: typeof s; // string
```

## 활용

- 기본 타입 자체는 별로 유용하지 않음 → 다른 타입 연산자와 조합할 때 강력해짐

```typescript
type Predicate = (x: unknown) => boolean;
type K = ReturnType<Predicate>; // boolean

function f() { return { x: 10, y: 3 }; }
type P = ReturnType<typeof f>;  // { x: number; y: number }
// ReturnType 은 함수 "타입" 을 받으므로, typeof f 로 f 의 타입을 가져와야 함
```

## 제약

- `typeof` 는 **식별자** 나 그 프로퍼티에만 사용 가능
- 함수 호출 결과 같은 임의의 표현식에는 사용 불가

```typescript
let shouldContinue: typeof msgbox("Are you sure?");
// error: 함수 호출 표현식에는 typeof 사용 불가
```

- 이건 값의 세계와 타입의 세계를 헷갈리지 않게 하기 위함

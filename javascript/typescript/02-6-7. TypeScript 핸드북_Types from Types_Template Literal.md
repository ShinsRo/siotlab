# Template Literal Types

## 템플릿 리터럴 타입

- JS 템플릿 리터럴 문법과 유사하지만 **타입 위치** 에서 사용
- 문자열 리터럴 타입을 기반으로 새로운 문자열 리터럴 타입 생성

```typescript
type World = "world";
type Greeting = `hello ${World}`; // "hello world"
```

- 보간 위치에 유니언을 넣으면 → 모든 조합의 유니언이 생성됨

```typescript
type EmailLocaleIDs = "welcome_email" | "email_heading";
type FooterLocaleIDs = "footer_title" | "footer_sendoff";

type AllLocaleIDs = `${EmailLocaleIDs | FooterLocaleIDs}_id`;
// "welcome_email_id" | "email_heading_id" | "footer_title_id" | "footer_sendoff_id"
```

- 여러 유니언을 곱집합처럼 결합 가능 → 조합 폭발에 주의

```typescript
type Lang = "en" | "ja" | "pt";
type LocaleMessageIDs = `${Lang}_${AllLocaleIDs}`;
```

## 타입 안의 문자열 유니언

- 실제 강점은 기존 문자열 리터럴 타입을 기반으로 새로운 리터럴을 정의할 때

```typescript
type PropEventSource<Type> = {
  on<Key extends string & keyof Type>(
    eventName: `${Key}Changed`,
    callback: (newValue: Type[Key]) => void
  ): void;
};

declare function makeWatchedObject<Type>(obj: Type): Type & PropEventSource<Type>;

const person = makeWatchedObject({
  firstName: "Saoirse",
  lastName: "Ronan",
  age: 26,
});

person.on("firstNameChanged", (newName) => { /* newName: string */ });
person.on("ageChanged", (newAge) => { /* newAge: number */ });
person.on("firstName", () => {}); // error: "firstNameChanged" 등이어야 함
```

## 템플릿 리터럴 안에서의 추론

- 콜백 인자 타입까지 정확히 추론 가능
- `${infer Prop}Changed` 패턴을 활용해 원본 키를 추출

```typescript
type PropEventSource<Type> = {
  on<Key extends string & keyof Type>(
    eventName: `${Key}Changed`,
    callback: (newValue: Type[Key]) => void
  ): void;
};
```

- 위 예제에서 `on("firstNameChanged", ...)` 호출 시 `Key` 는 `"firstName"` 으로 추론됨

## 내장 문자열 조작 타입 (Intrinsic String Manipulation Types)

TS 는 문자열 조작을 돕는 네 가지 내장 유틸리티 타입 제공:

- `Uppercase<StringType>` — 대문자 변환
- `Lowercase<StringType>` — 소문자 변환
- `Capitalize<StringType>` — 첫 글자 대문자
- `Uncapitalize<StringType>` — 첫 글자 소문자

```typescript
type Greeting = "Hello, world";
type ShoutyGreeting = Uppercase<Greeting>;    // "HELLO, WORLD"
type QuietGreeting = Lowercase<Greeting>;     // "hello, world"

type Lower = "hello";
type Upper = Capitalize<Lower>;               // "Hello"

type Big = "HELLO";
type Small = Uncapitalize<Big>;               // "hELLO"
```

- 이들은 컴파일러에 내장되어 있으며 JS 파일로는 존재하지 않음
- 매핑된 타입에서 키 재매핑 (`as`) 과 결합해 getter/setter 유틸리티 등을 만들 때 유용

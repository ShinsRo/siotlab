# Conditional Types

## 조건부 타입

- `SomeType extends OtherType ? TrueType : FalseType` 형태
- JS 의 삼항 연산자와 유사

```typescript
interface Animal { live(): void; }
interface Dog extends Animal { woof(): void; }

type Example1 = Dog extends Animal ? number : string; // number
type Example2 = RegExp extends Animal ? number : string; // string
```

## 활용 — 오버로드 대체

- 오버로드 시그니처를 조건부 타입으로 표현 → 훨씬 유연

```typescript
interface IdLabel { id: number; }
interface NameLabel { name: string; }

type NameOrId<T extends number | string> =
  T extends number ? IdLabel : NameLabel;

function createLabel<T extends number | string>(idOrName: T): NameOrId<T> {
  throw "unimplemented";
}

let a = createLabel("typescript");   // NameLabel
let b = createLabel(2.8);            // IdLabel
let c = createLabel(Math.random() ? "hello" : 42); // NameLabel | IdLabel
```

## 조건부 타입 제약

- 조건 안에서 특정 프로퍼티를 갖도록 제약 가능
- 없다면 `never`, 있다면 그 프로퍼티 타입을 반환

```typescript
type MessageOf<T extends { message: unknown }> = T["message"];

interface Email { message: string; }
type EmailMessageContents = MessageOf<Email>; // string
```

- 제약 없이 처리하려면 조건부 타입 안에서 조건을 걸면 됨

```typescript
type MessageOf<T> = T extends { message: unknown } ? T["message"] : never;

interface Dog { bark(): void; }
type DogMessageContents = MessageOf<Dog>; // never
```

- 배열에서 요소 타입 꺼내기

```typescript
type Flatten<T> = T extends any[] ? T[number] : T;
type Str = Flatten<string[]>; // string
type Num = Flatten<number>;   // number
```

## 조건부 타입 안에서 추론 (`infer`)

- `infer` 로 조건에 등장하는 타입을 캡처 가능
- 예: 배열 요소 타입 추론

```typescript
type Flatten<Type> = Type extends Array<infer Item> ? Item : Type;
```

- 함수의 반환 타입 추론

```typescript
type GetReturnType<Type> =
  Type extends (...args: never[]) => infer Return ? Return : never;

type Num = GetReturnType<() => number>;          // number
type Str = GetReturnType<(x: string) => string>; // string
```

- 오버로드된 함수에 대해 `infer` 를 쓰면 **가장 마지막 시그니처** 로 추론됨

## 분산 조건부 타입 (Distributive Conditional Types)

- 조건부 타입이 **제네릭 타입** 에 적용되면, 유니언에 대해 **각 멤버마다 분산 적용**

```typescript
type ToArray<Type> = Type extends any ? Type[] : never;

type StrArrOrNumArr = ToArray<string | number>;
// = ToArray<string> | ToArray<number>
// = string[] | number[]
```

- 분산을 원하지 않으면 `extends` 양쪽에 `[]` 로 감싸기

```typescript
type ToArrayNonDist<Type> = [Type] extends [any] ? Type[] : never;
type StrArrOrNumArr = ToArrayNonDist<string | number>; // (string | number)[]
```
